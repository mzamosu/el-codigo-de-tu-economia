10.1 Clases y objetos: los moldes de tu código

1. El molde y la pieza

Antes de crear tus propias clases, fíjate en algo: ya llevas todo el curso trabajando con objetos sin ser consciente de ello. Cuando escribes categoria.upper() o gastos.append(45.50), estás llamando a un método de un objeto. El punto . es la clave: en POO, el punto separa el objeto de su método o atributo.

# categoria es un objeto de la clase str
categoria = "comida"
print(categoria.upper())        # Método: convierte a mayúsculas → "COMIDA"
print(categoria.replace("o","0")) # Método: reemplaza → "c0mida"

# gastos es un objeto de la clase list
gastos = [45.50, 32.00, 18.75]
gastos.append(120.00)           # Método: añade al final
print(len(gastos))              # 4

Python está construido sobre objetos. Ahora aprenderás a crear los tuyos propios.

Clases

Una clase es como un molde o plantilla que define qué características y funciones tendrán todos los objetos creados a partir de ella. La clase no es el objeto en sí: es la descripción de cómo será el objeto.

En Python una clase se define con la palabra reservada class, seguida del nombre de la clase que suele ponerse con la primera letra en mayúscula: 

  • Atributos: las características del objeto (qué tiene). Se definen como las variables.
  • Métodos: funciones del objeto (qué hace). Se definen como las funciones.

Ambos tienen que estar indentados por 4 espacios dentro de la clase.

Ejemplo del Gestor:

class Gasto:

    # Atributos: características que tendrá cada gasto
    importe   = 0.0
    categoria = ""
    fecha     = ""

    # Métodos: comportamientos del objeto
    def mostrar(self):
        print(f"{self.fecha} | {self.categoria:<12} | {self.importe:.2f} €")

    def es_elevado(self):
        return self.importe > 100

Constructor init y self

El código anterior funciona, pero tiene un problema: todos los objetos Gasto nacerían con los mismos valores por defecto (importe = 0.0, categoria = ""). Para que cada objeto nazca ya con sus propios datos, Python usa un método especial llamado constructor: __init__.

El constructor se ejecuta automáticamente cada vez que creas un nuevo objeto y es donde se asignan los valores iniciales de sus atributos:

class Gasto:

    # Constructor: se ejecuta al crear cada objeto
    def __init__(self, importe, categoria, fecha):
        self.importe   = importe    # Atributo del objeto
        self.categoria = categoria  # Atributo del objeto
        self.fecha     = fecha      # Atributo del objeto

    # Métodos: comportamientos del objeto
    def mostrar(self):
        print(f"{self.fecha} | {self.categoria:<12} | {self.importe:.2f} €")

    def es_elevado(self):
        return self.importe > 100

¿Qué es self?

self hace referencia al propio objeto que se está creando. Es obligatorio como primer parámetro en todos los métodos de una clase, aunque no lo pasas tú al llamarlos: Python lo gestiona automáticamente.

Piensa en self como "yo mismo": cuando el objeto gasto1 llama a mostrar(), self es gasto1. Cuando lo llama gasto2, self es gasto2.

Crear objetos: instanciación

Una vez definida la clase, para usar los objetos es necesario crearlos, para ello utilizamos el nombre de la clase con los parámetros, entre paréntesis, si fueran necesarios:

# Creamos tres objetos de la clase Gasto
gasto1 = Gasto(45.50,  "comida",      "01/11/2024")
gasto2 = Gasto(120.00, "casa",        "05/11/2024")
gasto3 = Gasto(18.75,  "transporte",  "08/11/2024")

# Accedemos a sus atributos con la notación punto
print(gasto1.importe)       # 45.5
print(gasto2.categoria)     # casa

# Llamamos a sus métodos con la notación punto
gasto1.mostrar()            # 01/11/2024 | comida        | 45.50 €
gasto2.mostrar()            # 05/11/2024 | casa          | 120.00 €
print(gasto3.es_elevado())  # False

Guardar objetos en lista

En tu Gestor de Gastos querrás registrar muchos gastos. La forma natural es guardar los objetos en una lista:

# Lista de objetos Gasto
gastos = []

# Añadimos gastos
gastos.append(Gasto(45.50,  "comida",      "01/11/2024"))
gastos.append(Gasto(120.00, "casa",        "05/11/2024"))
gastos.append(Gasto(18.75,  "transporte",  "08/11/2024"))

# Recorremos y mostramos todos
print(" Listado de gastos:")
for g in gastos:
    g.mostrar()

# Calculamos el total
total = sum(g.importe for g in gastos)
print(f"\n Total: {total:.2f} €")

Trabajando con objetos

Ya sabes crear objetos. Ahora veamos cómo trabajar con ellos de forma más completa: acceder a sus datos, modificarlos y hacer que se representen de forma inteligente.

Acceder y modificar atributos

Con la notación punto puedes leer y modificar los atributos de cualquier objeto directamente:

gasto1 = Gasto(45.50, "comida", "01/11/2024")

# Leer atributos
print(gasto1.importe)       # 45.5
print(gasto1.categoria)     # comida

# Modificar un atributo
gasto1.importe = 50.00
print(gasto1.importe)       # 50.0

# Usar atributos en expresiones
presupuesto = 500
if gasto1.importe > presupuesto * 0.10:
    print(" Gasto considerable")

Método str

Cuando intentas imprimir un objeto directamente, Python muestra algo poco útil como <__main__.Gasto object at 0x...>. Para solucionarlo existe el método especial __str__: define cómo se representa el objeto como texto:

class Gasto:

    def __init__(self, importe, categoria, fecha):
        self.importe   = importe
        self.categoria = categoria
        self.fecha     = fecha

    def __str__(self):
        return f"{self.fecha} | {self.categoria:<12} | {self.importe:.2f} €"

    def es_elevado(self):
        return self.importe > 100


# Ahora print() muestra algo útil
gasto1 = Gasto(45.50, "comida", "01/11/2024")
print(gasto1)    # 01/11/2024 | comida       | 45.50 €

__str__ se llama automáticamente cuando usas print(objeto) o str(objeto). Es el equivalente a decirle al objeto: "cuando alguien te pida que te muestres como texto, hazlo así".
