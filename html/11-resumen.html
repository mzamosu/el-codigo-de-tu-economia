TC2 - Situación de aprendizaje 1.3: Desarrollo de Software: El código de tu economía

11. Resumen

1. Importante

Antes de comenzar a construir tu Gestor de Gastos Personales, asegúrate de que dominas los contenidos fundamentales de esta SdA. Repasa cada apartado y, si alguno no te queda claro, vuelve al bloque correspondiente antes de continuar.

El idioma de las máquinas

  • Los lenguajes de alto nivel están diseñados para el programador; los de bajo nivel, para el ordenador.
  • Los lenguajes compilados traducen todo el código de una vez; los interpretados (como Python) lo hacen línea a línea.
  • Todo programa sigue la estructura Entrada → Procesamiento → Salida.
  • Python es un lenguaje interpretado, gratuito, sencillo y muy demandado en el mercado laboral.
  • El entorno de trabajo será VS Code.

Los cimientos del código

  • Una variable es un contenedor con nombre que almacena un dato. Una constante no cambia (se escribe en MAYÚSCULAS por convenio),
  • Los tipos de datos básicos son: int (entero), float (decimal), str (texto) y bool (verdadero/falso).
  • type() permite conocer el tipo de dato de una variable; int(), float() y str() convierten entre tipos.
  • Los operadores aritméticos (+, -, *, /, //, %) realizan cálculos matemáticos.
  • Los operadores de asignación (=, +=, -=) asignan o actualizan el valor de una variable.
  • Los operadores de comparación (==, !=, >, <, >=, <=) devuelven True o False.
  • Los operadores lógicos (and, or, not) combinan condiciones.
  • input() recoge datos del usuario siempre como texto; print() muestra resultados; las f-strings formatean la salida.

El programa decide y repite

  • La estructura if / elif / else ejecuta bloques de código según se cumplan condiciones.
  • La indentación (4 espacios) es obligatoria en Python para definir los bloques de código.
  • El bucle for repite un bloque un número determinado de veces; se usa con range() o para recorrer colecciones.
  • El bucle while repite mientras se cumpla una condición; puede usarse como contador o acumulador.
  • break sale del bucle inmediatamente; continue salta a la siguiente iteración.
  • Un bucle infinito ocurre cuando la condición nunca se vuelve False; se controla con break o actualizando la variable.

Organiza tus datos

  • Una lista ([ ]) es ordenada, modificable y permite duplicados → ideal para almacenar los importes del mes.
  • Una tupla (( )) es ordenada e inmutable → ideal para las categorías fijas del sistema.
  • Un diccionario ({clave: valor}) accede a los datos por nombre → ideal para el total por categoría.
  • Un conjunto ({ }) no admite duplicados ni orden → ideal para obtener las categorías únicas usadas.
  • Métodos principales de lista: append(), insert(), remove(), pop(), sort(), reverse(), count(), extend().

Divide y reutiliza

  • Una función se define con def, recibe parámetros y puede devolver un resultado con return.
  • El principio DRY (Don't Repeat Yourself): escribe el código una vez y reutilízalo todas las veces que necesites.
  • Las variables locales solo existen dentro de la función; las globales son accesibles desde todo el programa.
  • Las bibliotecas estándar (datetime, csv, json, os, tkinter) vienen incluidas con Python.
  • Las bibliotecas de terceros (matplotlib) necesitan instalarse con pip install.
  • import biblioteca importa el módulo completo; from biblioteca import función importa solo lo necesario.

La memoria a largo plazo

  • Abre siempre los archivos con with open(...) as f: — se cierra automáticamente aunque ocurra un error.
  • Modos de apertura: "r" (leer), "w" (escribir desde cero), "a" (añadir), "x" (crear nuevo).
  • Usa os.path.exists() antes de abrir un archivo para evitar errores en la primera ejecución.
  • json.dump() guarda listas y diccionarios; json.load() los recupera. Añade siempre ensure_ascii=False.
  • El bloque try / except captura errores y evita que el programa se cierre bruscamente.
  • Captura siempre al menos FileNotFoundError y json.JSONDecodeError al trabajar con archivos

El mundo en objetos

  • Una clase es el molde que define atributos y métodos; un objeto es una instancia concreta de esa clase.
  • El constructor __init__ se ejecuta automáticamente al crear un objeto y asigna sus valores iniciales.
  • self hace referencia al propio objeto — es obligatorio como primer parámetro en todos los métodos.
  • El método __str__ define cómo se muestra el objeto al usar print().
  • La herencia permite que una clase hija reutilice los atributos y métodos de la clase padre.
  • super().__init__() llama al constructor del padre desde la clase hija sin repetir código.
  • isinstance(objeto, Clase) comprueba de qué tipo es un objeto — útil cuando mezclas tipos en una lista.

¿Estás listo para el reto?
Antes de pasar a construir tu Gestor de Gastos comprueba que:

☑️ Sabes crear variables, listas, tuplas y diccionarios en Python.
☑️ Puedes escribir un menú interactivo con while y if/elif/else.
☑️ Sabes dividir el código en funciones con def.
☑️ Entiendes cómo guardar y cargar datos con json y os.
☑️ Conoces la diferencia entre una clase padre y una clase hija.
