5.2 Operadores y expresiones

1. Operadores

En la página anterior aprendiste a crear "cajas" (variables) para guardar tus datos. Pero, ¿de qué sirve tener el importe de una factura guardado si no puedes hacer nada con él? Para que tu Gestor de Gastos sea útil, necesita procesar esa información: sumar tickets, restar gastos del saldo o comprobar si te has pasado del presupuesto.

Para realizar todas estas acciones, Python utiliza los operadores. Piensa en ellos como las herramientas de tu taller: cada uno  sirve para una tarea específica. Una expresión no es más que una combinación de variables, constantes y operadores que el ordenador evalúa para obtener un resultado final.

Tipos de operadores que usarás en tu reto:

A lo largo de tu proyecto, utilizarás principalmente tres tipos de operadores:

  1. Operadores aritméticos (para hacer cuentas).
  2. Operadores lógicos (para combinar condiciones).
  3. Operadores de comparación (para tomar decisiones).
  4. Operadores de asignación.

Asignación

Ya conoces el operador = para asignar un valor a una variable. Pero Python tiene operadores de asignación compuestos que te permiten actualizar el valor de una variable de forma más compacta. En tu gestor los usarás continuamente para ir acumulando gastos: 

2. ¡Ojo con estos operadores!


Fíjate especialmente en estos tres, que suelen sorprender a los principiantes:

# División entera: devuelve solo la parte entera
print(17 // 5)         # Resultado: 3

# Módulo: devuelve el resto de la división
print(17 % 5)         # Resultado: 2

# Potencia
print(2 ** 8)          # Resultado: 256

En el Gestor de Gastos, el operador % te será muy útil para saber, por ejemplo, si el número de gastos es par o impar, y el // para calcular medias enteras.

Pero un programa que no se comunica con el usuario no sirve de mucho. Necesitamos que tu Gestor de Gastos hable contigo: que te pregunte cuánto ha costado el café de esta mañana y te informe rápidamente de cuánto dinero te queda.

En Python eso se hace con input() y print().

Función print()

Sirve para mostrar mensajes o el valor de tus variables en la pantalla. Imagina que es la "boca" de tu programa. Para usarla, solo tienes que poner entre paréntesis lo que quieres decir. Si es un texto fijo, va entre comillas; si es una variable, va sin comillas.

saldo_actual=1200
total=500
print("¡Atención! Te estás acercando al límite")
print(saldo_actual)
print(f"Total gastado este mes: {total} €")   # Con f string combina texto y variables en Python

Función input()

Esta es la "oreja" de tu programa. Sirve para que el ordenador pause la ejecución y se quede esperando a que tú (el usuario) escribas algo en el teclado y pulses la tecla Enter. Lo que el usuario escriba, normalmente lo guardaremos dentro de una variable.

#Pedir el importe y convertirlo a número decimal
importe  = float(input("Introduce el importe del gasto: "))

#Pedir la categoría (texto, no necesita conversión)
categoria = input("Introduce la categoría (comida, ocio...): ")

#Pedir el presupuesto mensual y convertirlo a entero
presupuesto = int(input("¿Cuál es tu presupuesto mensual? "))

Recuerda: input() siempre devuelve un str. Si intentas sumar ese valor directamente sin convertirlo obtendrás un error.

7. Importante

Operadores aritméticos

Son las herramientas matemáticas (+, -, *, /) que te permiten realizar los cálculos numéricos de tu Gestor de Gastos (sumar totales, restar del saldo).

Operadores de comparación y lógicos

 Los de comparación (==, !=, >, etc.) comparan valores devolviendo True o False. Los lógicos (and, or, not) permiten combinar estas comparaciones para crear condiciones más complejas (ej: gasto alto Y categoría ocio).

Mostrar datos (print)

La orden print() muestra información en la pantalla. Puedes usarla para texto fijo o para ver qué hay dentro de tus variables.

Pedir datos (input)

La orden input() permite al usuario introducir información a través del teclado, guardando la respuesta en una variable.

Conversión de tipos

Recuerda que input() siempre captura texto. Si vas a pedir un número para hacer cálculos en tu Gestor, debes convertirlo a número entero o decimal envolviéndolo con int() o float(). Ejemplo: float(input("Importe: "))
