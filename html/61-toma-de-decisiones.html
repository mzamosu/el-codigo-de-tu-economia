6.1 Toma de decisiones

1. Estructuras condicionales

En tu día a día, tomas cientos de decisiones basadas en condiciones: "Si tengo saldo en la cuenta, compro las entradas; si no, espero al mes que viene". En Python, le enseñamos al ordenador a pensar exactamente de la misma manera utilizando la estructura if (que en inglés significa "si...", de condición).

Vamos a ver las tres piezas clave para construir la lógica de tu Gestor de Gastos:

Condición simple IF

Es la regla más básica. Le decimos al programa que compruebe una expresión matemática o lógica. Solo si el resultado es verdadero (True), ejecutará las instrucciones que vienen justo debajo.

Imagina que tienes un presupuesto de 100€ y acabas de introducir un ticket de 120€. El programa debería darte un aviso de alerta:

presupuesto = 100
gasto = 120

if gasto > presupuesto:
    print("¡Alerta roja! Has superado tu presupuesto mensual.")

Plan B: ELSE (Si no...)

¿Qué pasa si la condición del if no se cumple (por ejemplo, el gasto es de solo 40€)? El programa, por defecto, se salta ese bloque y no hace nada. Pero a veces queremos que haga otra cosa en ese caso. Para eso usamos la palabra else.

presupuesto = 100
gasto = 120

if gasto > presupuesto:
    print("¡Alerta roja! Has superado tu presupuesto mensual.")
else:
    print("¡Todo en orden! Sigues dentro del límite.")

Múltiples opciones: ELIF (O si no, si...)

El if y el else te permiten elegir entre dos caminos. Pero, ¿qué pasa cuando hay más de dos posibilidades? Imagina que quieres clasificar tus gastos en tres niveles según el importe: bajo, moderado o elevado. Para eso existe el elif.

importe = 75

if importe < 20:
    print("💚 Gasto bajo")
elif importe < 50:
    print("🟡 Gasto moderado")
elif importe < 100:
    print("🟠 Gasto elevado")
else:
    print("🔴 Gasto muy elevado: ¿es necesario?")

Python evalúa las condiciones en orden, de arriba a abajo. En cuanto encuentra una que se cumple, ejecuta su bloque y salta el resto. Por eso el orden importa: coloca siempre las condiciones de más restrictiva a menos restrictiva.

Condiciones encadenadas

A veces una sola condición no es suficiente para tomar una decisión. En tu Gestor de Gastos puede que necesites comprobar varias cosas a la vez: que el gasto sea elevado y que además pertenezca a la categoría de ocio, o que se haya superado el presupuesto o que el número de gastos sea muy alto. Para eso puedes encadenar condiciones usando los operadores lógicos and y or que ya conoces:

importe = 75
categoria = "ocio"
total = 480
presupuesto = 500

# AND: se deben cumplir AMBAS condiciones
if categoria == "ocio" and importe > 50:
    print("Gasto de ocio elevado: revisa si es necesario")

# OR: basta con que se cumpla UNA de las dos
if total > 450 or importe > 100:
    print("Atención: estás cerca del límite mensual")

# Combinación de AND y OR con paréntesis
if (categoria == "ocio" and importe > 50) or total > presupuesto:
    print("Alerta de gasto: revisa tu presupuesto")

Cuando combinas and y or en una misma condición, usa paréntesis para dejar claro el orden de evaluación. Igual que en matemáticas, los paréntesis se evalúan primero y evitan resultados inesperados.
Recuerda: con and ambas condiciones deben ser True para que el bloque se ejecute. Con or basta con que una lo sea.

2. La regla de oro de Python: la indentación

Fíjate muy bien en los ejemplos de código anteriores. Las órdenes print() que van por dentro del if, elif o else no empiezan pegadas al margen izquierdo, sino que tienen un espacio hacia la derecha (una tabulación o sangría). Así es como Python sabe visualmente qué instrucciones pertenecen a la condición. Si olvidas esta sangría, VSCode te marcará la línea en rojo y el programa dará error. Esta tabulación se consigue dejando 4 espacios al comienzo de cada línea o pulsando la tecla tabulador. 

presupuesto = 500
total = 320

# ✅ Correcto
if total > presupuesto:
    print("Presupuesto superado")   # 4 espacios de sangría
    print("Revisa tus gastos")      # mismo nivel

# ❌ Error: falta indentación
if total > presupuesto:
print("Presupuesto superado")       # Python no sabe que pertenece al if

VS Code añade la indentación automáticamente al pulsar Enter después de los dos puntos. Si ves que algo no funciona, revisa siempre la sangría primero.

5. El guardián de tu cartera

¿Recuerdas el programa ¡Hola, Gestor! que escribiste antes? Ha llegado el momento de mejorarlo. Vas a programar el sistema de avisos de tu Gestor de Gastos siguiendo estos pasos:

  1. Crea un archivo llamado alertas.py. Tu objetivo es programar el sistema de avisos de tu Gestor de Gastos.
  2. Crea una variable llamada saldo y asígnale el valor de tu dinero actual (por ejemplo, 50).
  3. Pide al usuario por teclado (usando input y float) que introduzca el importe de su última compra y guárdalo en la variable compra.
  4. Crea la estructura de decisión:
    • SI la compra es mayor que el saldo, muestra en pantalla: "Operación denegada. No tienes fondos suficientes."
    • SI NO, calcula el nuevo saldo (restando la compra al saldo), y muestra en pantalla: "Compra aceptada. Tu nuevo saldo es de X euros."

¡Inténtalo sin mirar la solución! Ejecuta tu código un par de veces introduciendo números diferentes para comprobar que el programa sabe tomar ambos caminos de forma inteligente.

Mostrar retroalimentación

# 1. Establecemos nuestro saldo inicial
saldo = 50.0

# 2. Pedimos el gasto al usuario (convertido a decimal)
compra = float(input("¿De cuánto es tu ticket de compra?: "))

# 3. Estructura de decisión
if compra > saldo:
    print("Operación denegada. No tienes fondos suficientes.")
else:
    saldo = saldo - compra
    print("Compra aceptada. Tu nuevo saldo es de:", saldo, "euros.")

6. Importante

El bloque if

 Es la estructura principal. Evalúa una condición y, si es verdadera (true), ejecuta las instrucciones tabuladas en su interior.

Las alternativas elif y else

Se utilizan justo después de un if. Elif permite añadir más comprobaciones encadenadas, y else se ejecuta automáticamente como último recurso cuando ninguna de las condiciones anteriores se ha cumplido.

La indentación

En Python es obligatorio utilizar una sangría (indentación) en el código que va dentro de las estructuras de control. Esta sangría se consigue normalmente dejando cuatro espacios al comienzo de cada línea y sirve para indicar qué instrucciones pertenecen a cada bloque de código. Otros lenguajes de programación utilizan llaves {} para delimitar estos bloques.

Condiciones encadenadas (and / or)

A veces necesitas que tu programa compruebe varias cosas al mismo tiempo antes de tomar una decisión. Para unir varias condiciones en una sola línea, utilizamos los operadores lógicos:

  • and (Y lógico): obliga a que todas las condiciones sean verdaderas para que se ejecute el código. Es ideal para ser muy específico.
      • Ejemplo: avisar solo si el gasto es alto Y además es de una categoría prescindible.
      • if compra > 100 and categoria == "Ocio":
  • or (O lógico): basta con que al menos una de las condiciones sea verdadera. Es muy útil para agrupar opciones.
      • Ejemplo: clasificar un ticket como "Gasto del Hogar" si es de luz o si es de agua.
      • if recibo == "Luz" or recibo == "Agua":
